## O que este portfólio demonstra

Este projeto foi construído em **Next.js + React + TypeScript + Tailwind CSS** e apresenta meu padrão de trabalho em:

- arquitetura visual e hierarquia de conteúdo;
- desenvolvimento responsivo para desktop e mobile;
- componentes reutilizáveis;
- SEO e metadados para compartilhamento;
- experiência de usuário e chamadas para conversão;
- publicação e manutenção de aplicações web modernas.

## Como executar localmente

```bash
npm install
npm run dev
```

Acesse:

```text
http://localhost:3000
```

Para gerar a versão de produção:

```bash
npm run build
npm run start
```
